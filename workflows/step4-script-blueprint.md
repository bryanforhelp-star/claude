# Step 4 — Find Outliers & Build the Script Blueprint

**Tool:** Claude AI

## What This Step Does

Now that you have your video ideas, you go back to the competitor channel and find the most viewed videos that were uploaded recently — these are called outliers. You copy the transcript from 3 of these high-performing videos, then send all 3 transcripts to Claude with a forensic analysis prompt.

Claude extracts every reusable writing pattern — structure, tone, hooks, transitions, pacing — into a master Script Blueprint. This blueprint ensures any future script matches the proven voice and style of what's already working. The result is a living document that your Upwork script writer can reference for every single video they produce on your behalf, removing the need for lengthy creative briefs and dramatically reducing revision cycles.

## How To Use It

### 1. Find Recent Outliers
Go to the competitor channel and find the most viewed videos uploaded recently.

### 2. Copy Transcripts
For each video, go to the description, click "Show Transcript", and copy the full transcript. Do this for 3 high-performing videos.

### 3. Send to Claude
Send all 3 transcripts to Claude along with the Script Blueprint prompt from [`prompts/step4-script-blueprint.md`](../prompts/step4-script-blueprint.md).

### 4. Save the Blueprint
Claude will return a comprehensive Script Blueprint. Save this — you'll use it every time you create a new video.

## Why This Matters

The Script Blueprint is what makes your videos indistinguishable from the competitor's best content. Without it, your scripts are generic. With it, they match the exact voice, pacing, and structure that's already proven to retain viewers and drive watch time.
