# Step 1 — Analyse the Competitor Channel

**Tool:** Claude in Chrome (Opus 4.6)

## What This Step Does

You open a competitor YouTube channel that's posting content in your target niche and getting millions of views. Using Claude's Chrome extension set to Opus 4.6, you run a deep analysis prompt that examines their titles, thumbnails, title templates, and performance patterns. This tells you exactly what's working so you can replicate only the winning patterns and skip the trial and error.

This is the foundational data layer of the entire system. Every title you generate, every script blueprint you build, and every outline you create downstream all trace back to the intelligence gathered in this step.

## How To Use It

### 1. Find a Competitor Channel
Pick a YouTube channel in your niche that's making money with consistent uploads and strong view counts. Look for:
- Channels with 50K+ subscribers
- Regular upload schedule (at least weekly)
- Mix of viral hits and average performers
- Similar content format to what you want to create

### 2. Open Claude's Chrome Extension
Navigate to the channel's Videos page and open Claude's Chrome extension. Make sure it's set to Opus 4.6.

### 3. Send the Analysis Prompt
Copy the prompt from [`prompts/step1-channel-analysis.md`](../prompts/step1-channel-analysis.md) and send it. Claude will perform a forensic analysis of the channel.

### 4. Save the Output
Save Claude's complete analysis — you'll use it in Steps 3 and beyond. Export it as a PDF for easy re-attachment.

## Why This Matters

This analysis becomes the foundation of everything. Without real performance data from a proven channel, every downstream step is guesswork. With it, you're working from ground truth.
