# System Overview — YouTube Monetization Automation

## How It Works

This system uses Claude AI to analyse a competitor channel, research trending topics, generate viral titles, and build complete script blueprints — all in under an hour. You then hand those titles and outlines to a production team sourced from Upwork at $75 per video. Each phase feeds directly into the next, creating a compounding effect where data from early steps powers better outputs in later ones.

## The Complete Workflow

```
┌─────────────────────┐
│  1. Analyse Channel  │ ← Claude in Chrome (Opus 4.6)
│  Deep forensic       │   16-step title analysis
│  analysis            │   Output: Title Blueprint + 30 titles
└─────────┬───────────┘
          │
┌─────────▼───────────┐
│  2. Google Trends    │ ← Google Trends (free)
│  Export real-time     │   Trending Now > US > 24hrs
│  trending data       │   Output: CSV with ~200 topics
└─────────┬───────────┘
          │
┌─────────▼───────────┐
│  3. Generate Titles  │ ← Claude AI
│  Cross-reference     │   Analysis PDF + Trends CSV
│  trends + formulas   │   Output: 20 ranked titles
└─────────┬───────────┘
          │
┌─────────▼───────────┐
│  4. Script Blueprint │ ← Claude AI
│  Extract patterns    │   3 outlier transcripts
│  from outliers       │   Output: Master Script Bible
└─────────┬───────────┘
          │
┌─────────▼───────────┐
│  5. Video Outline    │ ← Claude AI
│  Full outline built  │   Title + Script Blueprint
│  from blueprint      │   Output: Production-ready outline
└─────────┬───────────┘
          │
┌─────────▼───────────┐
│  6. Production       │ ← Upwork ($75/video)
│  Delegate to         │   Script writer + editor + designer
│  freelancers         │   Output: Published video
└─────────────────────┘
```

## Monthly Workflow Cadence

| Week | Activity | Time |
|------|----------|------|
| Week 1 | Run Steps 1–3 (analysis + trends + titles) | ~1 hour |
| Week 1 | Run Step 4 (script blueprint — one-time, then reuse) | ~30 min |
| Week 1–2 | Run Step 5 for each title (video outlines) | ~15 min each |
| Week 2–4 | Step 6: Review deliverables, publish | ~1 hour/week |

**Total weekly time:** Under 8 hours (including review and publishing).

## Scaling Strategy

Once the first channel is profitable and running smoothly:

1. **Same niche, more volume** — Increase from 4 to 8 videos/month
2. **New niche** — Launch a second channel using the same system
3. **Team expansion** — Add a second editor to handle increased volume
4. **Re-run analysis monthly** — Fresh trends data keeps titles relevant

## Key Metrics to Track

| Metric | Target | Where to Check |
|--------|--------|----------------|
| Views per video (Week 1) | 50K+ | YouTube Studio |
| Click-through rate (CTR) | 8%+ | YouTube Studio |
| Average view duration | 50%+ of video length | YouTube Studio |
| Cost per video | ~$75 | Upwork invoices |
| Revenue per 1K views (RPM) | $5–15 depending on niche | YouTube Studio |
| Monthly video output | 4–8 videos | Production tracker |

## Important Notes

- The Script Blueprint (Step 4) is a one-time setup per channel. Once built, you reuse it for every video.
- Re-run Steps 1–3 monthly to stay current with trending topics.
- Step 5 (outlines) takes ~15 minutes per video — batch 4–8 at a time.
- Consistency of publishing matters more than perfection of any single video.
