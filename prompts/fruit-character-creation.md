# Fruit Drama — Character Creation Prompts

> Use these prompts in Nano Banana (nanobana.ai), Midjourney, or DALL-E 3.
> The goal is a consistent, original character universe — NOT copies of existing cartoons.

---

## Design Philosophy

- Draw inspiration from Pixar / animated movie style but build your OWN visual identity
- Every character needs a signature visual quirk (accessory, expression default, color accent)
- Generate 3–5 reference images per character before animating — lock the look
- Save all reference images and use them as style seeds for every future generation

---

## Base Character Prompt Formula

```
[FRUIT/VEGETABLE TYPE] character, [EMOTIONAL EXPRESSION], [SIGNATURE ACCESSORY],
[LIGHTING STYLE], Pixar-style 3D animation, ultra detailed, cinematic quality,
original character design, expressive face, [POSE/ACTION]
```

## Consistency Tips

**Problem:** AI generates slightly different character faces each time.

**Fix — Style Seed Method:**
1. Generate your character once with the base prompt
2. Save the best result as your "style seed" image
3. On every future generation, attach the seed image and add:
   ```
   Maintain exact same character design as reference image.
   Same face shape, same accessories, same color palette.
   Only change: expression and pose.
   ```

**Fix — Character Sheet Generation:**
Generate a character sheet first:
```
Character sheet for [CHARACTER NAME], 3D Pixar-style animated [FRUIT] character.
Show 6 expressions in a grid: happy, sad, angry, shocked, guilty, smug.
Same character design throughout. White background. Ultra detailed.
```
Use this sheet as the reference for all future images of that character.

## Group Shot (All Characters in One Frame)

For scenes requiring multiple characters:

```
3D Pixar-style animated group scene: banana character, strawberry character,
and broccoli character all in the same frame at a backyard BBQ.
Each character has distinct facial expression matching their role.
Cinematic wide shot, golden hour lighting, ultra detailed.
[Attach individual character sheets as style seeds]
```

```
No characters — background plate only.
```

```
warm overhead light, modern cabinets, fruit bowl on counter.
No characters — background plate only.
```
